# Lab 8: BMI Calculator

## Mô tả

Ứng dụng nhận giới tính, chiều cao, cân nặng và tuổi để tính chỉ số BMI. Kết quả được phân loại thành Underweight, Normal hoặc Overweight trên màn hình riêng.

## Chức năng

- Chọn Male hoặc Female
- Điều chỉnh chiều cao từ 120 đến 220 cm
- Tăng giảm cân nặng và tuổi
- Tính BMI và hiển thị nhận xét
- Quay lại bằng nút RE-CALCULATE

## Công nghệ

- Flutter
- Dart

## Cách chạy

```bash
flutter pub get
flutter run
```
